# 课堂智能点名

> **说明：本项目主要通过 AI 辅助编程完成，用于个人教学场景下的功能探索、学习与测试。项目不作为正式教学管理系统或商业软件使用。**

这是一个无需后端服务器、以手机端使用为主的 PWA 课堂智能点名工具。

项目尝试根据学生成绩、题目难度、历史点名情况等信息计算候选权重，为教师提供若干名候选学生，并由教师根据实际课堂情况决定最终回答问题的学生。

学生资料、考试记录、应用设置、今日缺席、特别关注以及点名历史等数据均保存在当前设备浏览器的 **IndexedDB** 中。

**本 GitHub 仓库不包含真实学生名单、成绩文件及其他学生个人隐私数据。**

---

## 主要功能

- 支持多个班级学生数据
- 导入智学网原始 Excel 成绩文件
- 保存多次考试及成绩记录
- 根据题目难度智能生成候选学生
- 根据历史点名情况动态调整候选权重
- 支持特别关注学生
- 支持今日缺席设置
- 支持教师从候选学生中手动选择
- 支持“换一个更合适的学生”
- 查看最近 20 / 50 / 100 次及全部点名统计
- 使用 IndexedDB 在设备本地保存数据
- 支持 PWA 安装及核心功能离线使用

## 在电脑上启动

本项目是纯前端 PWA，不需要后端服务器。

在项目目录运行一个本地静态文件服务器，例如：

```bash
py -m http.server 4173
```

然后在浏览器打开：

```text
http://localhost:4173/
```

不要直接双击 `index.html` 运行，因为 PWA 的 Service Worker 需要在 HTTP 或 HTTPS 环境下工作。

## 第一次测试

1. 打开应用中的“数据”页面。
2. 选择保存在本地设备中的 **智学网原始成绩 `.xlsx` 文件**进行导入。
3. 检查程序识别出的考试名称、日期、班级和学生数量等信息。
4. 确认导入后，进入“点名”页面。
5. 选择班级和题目难度。
6. 点击“生成候选”。
7. 系统生成候选学生后，由教师手动选择实际回答问题的学生。
8. 候选学生仅进入候选列表时不会写入点名历史，教师实际点击学生姓名后才正式记录一次点名。
9. 可以使用“换一个更合适的学生”功能，测试提高能力要求后的候选推荐。
10. 在“学生”页面测试特别关注和今日缺席功能。
11. 在“统计”页面查看最近 20 / 50 / 100 次或全部点名历史。

## 智能点名

系统不会简单地随机抽取学生，而是根据多个因素动态计算学生进入候选名单的权重。

目前主要考虑：

- 学生考试成绩
- 当前题目难度
- 最近的点名历史
- 学生近期被点名次数
- 点名后的权重衰减
- 特别关注状态
- 今日缺席状态
- 高分学生的候选权重调整

题目难度由教师在点名前选择。

系统根据题目难度和学生成绩计算匹配程度，并结合历史点名情况生成候选学生。

系统只负责提供候选建议，**最终由教师根据课堂实际情况决定由哪位学生回答问题。**

---

## 候选机制

每次点名时，系统生成若干名候选学生。

候选人数可以根据程序设置进行调整。

候选学生旁会显示其在最近一定次数点名中的实际被选次数，例如：

```text
张三    最近20次：0次
李四    最近20次：1次
王五    最近20次：2次
```

教师点击其中一名学生后，该学生才会被正式写入点名历史。

因此：

```text
进入候选名单 ≠ 实际被点名
```

只有教师最终选择的学生才计入点名统计。

---

## 换一个更合适的学生

教师选择一名学生后，可以使用：

**“换一个更合适的学生”**

系统会提高对学生能力与当前问题难度的匹配要求，并重新生成一组候选学生。

已经实际被教师选择过的学生仍然保留在点名历史中。

这个功能主要用于课堂中出现当前学生难以继续回答、需要寻找更适合当前问题的学生时使用。

---

## 特别关注

教师可以将某些学生设置为“特别关注”。

特别关注学生会在后续候选计算中获得一定的权重提升，从而增加近期进入候选名单的机会。

特别关注状态可以随时设置或取消。

该功能不会强制选择某位学生，只影响其进入候选名单的概率。

---

## 今日缺席

教师可以将学生临时设置为“今日缺席”。

被设置为今日缺席的学生不会进入当天的候选名单。

缺席状态属于临时课堂状态，不会删除学生资料，也不会影响其历史考试和点名记录。

---

## 数据格式

本项目当前主要针对 **智学网导出的原始 Excel 成绩数据文件**进行解析和测试。

目前支持识别的智学网数据形式主要包括：

### 数智作业相关成绩工作簿

程序可以读取学生成绩表中的：

- 班级
- 学号 / 考号
- 姓名
- 总分
- 班级排名
- 年级或相关排名字段

### 所有班级学生小题得分明细工作簿

程序可以读取各班工作表中的：

- 准考证号
- 姓名
- 班级
- 总分
- 班次
- 校次等相关字段

如果检测到成绩采用 **150 分制**，程序会自动换算为百分制匹配分，用于点名算法计算，同时保留原始成绩 `rawScore`。

文件名中的练习名称和日期可以写入学生记录的：

- `source`
- `sourceDate`

等字段。

对于以下情况，程序会在导入过程中进行检查或提示：

- 数据为空
- 学号或考号重复
- 姓名缺失
- 成绩无法识别
- 表格结构无法识别

由于智学网导出的 Excel 文件格式可能随平台版本变化，本项目不能保证兼容智学网所有历史版本或未来版本的数据格式。

## 多次考试

系统支持保存多次考试数据。

每次选择智学网 Excel 成绩文件后，程序会尝试从文件名及文件内容中识别考试名称和日期。

教师确认后，系统新增一条独立考试记录，并保存该次考试中每位学生的：

- 原始成绩
- 用于算法计算的标准化成绩
- 班级名次
- 年级 / 校级相关名次
- 考试来源
- 考试日期

学生页面主要显示最近一次考试数据。

如果存在上一次考试，系统可以显示相应的排名变化，用于教师了解学生近期成绩变化。

---

## 数据存储

本项目不使用后端数据库。

主要数据保存在浏览器提供的 **IndexedDB** 中，包括：

- 学生资料
- 班级信息
- 考试信息
- 历次考试成绩
- 点名历史
- 特别关注状态
- 今日缺席状态
- 应用设置

因此，不同浏览器、不同设备以及不同网站地址之间的数据不会自动同步。

例如：

```text
电脑 Chrome
```

与：

```text
手机 Safari
```

属于不同的本地数据环境。

## 隐私说明

本项目代码仓库中**不提供、不保存、不发布真实学生成绩数据**。

真实学生 Excel 成绩文件应由使用者在自己的设备上本地选择和导入。

正常使用情况下，学生数据由浏览器读取后保存在当前设备的 IndexedDB 中。

请勿将包含以下内容的真实文件上传至公开 GitHub 仓库：

- 学生姓名
- 学号
- 准考证号
- 考试成绩
- 班级排名
- 年级排名
- 其他能够识别具体学生身份的信息

本项目仅用于个人教学辅助、功能探索与测试。

使用真实学生数据时，请使用者自行遵守所在学校、单位及所在地区关于学生个人信息、考试成绩和教育数据保护的相关规定。

## PWA 使用

本项目支持作为 PWA 使用。

部署到 HTTPS 网站后，可以使用支持 PWA 的浏览器访问。

例如部署到 GitHub Pages：

```text
https://用户名.github.io/classroom-picker/
```

首次正常加载后，Service Worker 会缓存应用运行所需的核心静态资源。

之后即使暂时没有网络，核心点名功能仍可继续使用。

学生资料和点名历史保存在当前设备的 IndexedDB 中。

### Android

使用 Chrome 等支持 PWA 的浏览器打开网站后，可以选择：

**安装应用**

或：

**添加到主屏幕**

### iPhone / iPad

使用 Safari 打开网站，然后选择：

**分享 → 添加到主屏幕**

即可从主屏幕启动应用。

---

## GitHub Pages

本项目支持部署在 GitHub Pages 的项目子目录中，例如：

```text
https://用户名.github.io/classroom-picker/
```

项目中的 Manifest、Service Worker、图标和静态资源路径均按照子目录部署方式配置。

GitHub Pages 默认提供 HTTPS，可以满足 PWA 和 Service Worker 的运行要求。

---

## 离线使用

首次使用时需要联网加载应用。

成功加载后，Service Worker 会缓存核心静态资源。

可以通过以下方法测试：

1. 联网打开应用。
2. 确认页面和功能正常。
3. 导入测试数据。
4. 关闭应用。
5. 关闭 Wi-Fi 和移动网络或开启飞行模式。
6. 从主屏幕重新打开 PWA。
7. 检查学生资料、点名和统计功能是否可以正常使用。

如果能够正常运行，说明离线缓存和 IndexedDB 工作正常。
