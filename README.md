# 课堂智能点名

这是一个无需服务器的手机优先 PWA。学生资料、每次考试记录、设置、今日缺席和点名历史都保存在浏览器 IndexedDB 中。

## 在电脑上启动

在项目目录运行一个静态文件服务器，例如：

```powershell
py -m http.server 4173
```

然后打开 `http://localhost:4173/`。不要直接双击 `index.html`，因为 PWA Service Worker 需要 HTTP 或 HTTPS 环境。

## 第一次测试

1. 打开“数据”，选择 `原始成绩文件` 中任意一个 `.xlsx`。
2. 确认导入提示，回到“点名”选择班级和难度。
3. 点击“生成候选”，候选进入列表但不会写历史；点击姓名后才写入历史。
4. 点击“换一个更合适的学生”验证更高能力要求的候选。
5. 在“学生”页测试特别关注和今日缺席，在“统计”页切换最近 20/50/100 次或全部历史。
6. 在“数据”页导出完整备份，再清除数据并恢复备份，确认数据回来了。

## 数据格式

导入器识别两类文件：

- “数智作业”工作簿：读取学生成绩表中的班级、学号/考号、姓名、总分及排名字段。
- “所有班级学生小题得分明细”工作簿：读取各班工作表中的准考证号、姓名、班级、总分和班次/校次；检测到 150 分制时自动换算成百分制匹配分，同时保留原始分数 `rawScore`。

文件名中的练习名称和日期会写入学生记录的 `source`、`sourceDate` 字段。空值、重复学号和无法识别的成绩会在导入结果中提示。

## 目录

- `algorithm.js`：候选推荐逻辑与集中配置
- `db.js`：IndexedDB 封装，包含学生、考试和考试成绩明细表
- `importer.js`：xlsx 解包、表头识别、成绩导入
- `app.js`：界面交互
- `exporter.js`：备份和历史导出
- `sw.js`、`manifest.json`：PWA 离线能力

## 多次考试

每次选择 Excel 后，程序会先显示从文件名识别出的考试名称和日期。编辑并确认后，系统新增一条独立考试记录，并保留该考试的每位学生成绩、班名次和段名次。学生页显示最近一次考试；如果存在上一次考试，会在对应名次后显示变化：红色表示名次数字变小、排名进步，绿色表示名次数字变大、排名退步。

在 Chrome/Edge 中打开后，可通过地址栏的安装按钮添加到手机或电脑主屏幕。首次打开后资源会缓存，之后核心功能可离线使用。
