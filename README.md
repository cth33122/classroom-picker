# 课堂智能点名
> **说明：本项目主要通过 AI 辅助编程完成，用于个人教学场景下的功能探索、学习与测试。项目不作为正式教学管理系统或商业软件使用。**
这是一个无需服务器的手机优先 PWA。学生资料、每次考试记录、设置、今日缺席和点名历史都保存在浏览器 IndexedDB 中。

## 在电脑上启动

进入项目目录，运行一个静态文件服务器，例如：

```powershell
py -m http.server 4173
```

在浏览器中打开 `http://localhost:4173/`。不能直接双击 `index.html`，PWA Service Worker 需要 HTTP 或 HTTPS 环境。

## 第一次测试

1. 打开“数据”，选择 `原始成绩文件` 中任意一个 `.xlsx`。
2. 确认导入提示，回到“点名”选择班级和难度。
3. 点击“简单”“适中”或“困难”生成候选；候选进入列表但不会写历史，点击姓名后才写入历史。
4. 选中学生后，可使用“缺席”撤销本次点名并标记当天缺席。
5. 在“学生”页打开学生详情测试特别关注、不参与点名和“备注”（可写文字、可添加图片），在“统计”页切换点名时间、点名统计和题目难度统计。
6. 在“数据”页可下载导入模板、导出完整备份，再清除数据并恢复备份，确认数据回来了。

## 数据格式

导入器识别两类文件：
- 两类文件源自“智学网”（教师端）下载的的原生全段成绩文件，分“数智作业”和“小题得分明细”。
- “数智作业”工作簿：读取学生成绩表中的姓名、班级、成绩及排名字段。
- “所有班级学生小题得分明细”工作簿：读取各班工作表中的姓名、班级、总分和班次/校次；检测到 150 分制时按该场考试总分换算成得分率，同时保留原始分数 `rawScore`。
- 一个工作簿可以包含多个工作表：工作表名形如“考试名称-日期”（如 `周测8-20270124`，也支持 `周测8 2027.01.24`、`周测8_20270124`、`20270124周测8` 等写法）时，每个工作表会各自成为一场考试，名称与日期直接从工作表名识别；名称中不含日期的工作表仍并入按文件名识别出的那场考试。

主要字段为姓名、班级、成绩、班次、段次。学号/考号是可选字段（可能只有“学号”“考号”“准考证号”“自定义考号”之一，也可能缺失），学生统一以“班级+姓名”作为身份标识，因此考号变动不会影响历史成绩的连续性。日期或名称取自工作表名/文件名后会写入学生记录的 `source`、`sourceDate` 字段；空姓名行、表尾的“年级均分”“注：…”等汇总行以及无法识别的成绩会在导入结果中提示或自动跳过。

## 目录

- `algorithm.js`：候选推荐逻辑与集中配置
- `db.js`：IndexedDB 封装，包含学生、考试和考试成绩明细表
- `importer.js`：xlsx 解包、表头识别、成绩导入
- `app.js`：界面交互
- `exporter.js`：备份和历史导出
- `sw.js`、`manifest.json`：PWA 离线能力

导入模板中的空白数据行需要填写后再导入；表头会自动识别班级、学号、姓名、成绩和排名字段。

## 多次考试

每次选择 Excel 后，程序会先显示识别出的考试名称、日期和总分。一个工作簿只含一场考试时显示单个确认卡片；包含多个“考试名称-日期”工作表时，会为每场考试各显示一张卡片，可分别修改名称、日期、总分，或取消勾选不需要的工作表后一次性保存。保存后系统为每场考试新增一条独立考试记录，并保留该考试的每位学生成绩、班名次和段名次。学生页显示最近一次考试；如果存在上一次考试，会在对应名次后显示变化：红色表示名次数字变小、排名进步，绿色表示名次数字变大、排名退步。

在 Chrome/Edge 中打开后，可通过地址栏的安装按钮添加到手机或电脑主屏幕。首次打开后资源会缓存，之后核心功能可离线使用。

## 导出成绩表格

“数据”页的“备份与恢复”里提供“导出成绩表格”按钮，生成一个 xlsx 文件：每场考试一个工作表，工作表名沿用“考试名称-日期”格式，表头为序号、姓名、班级、成绩、班次、段次、考号，并先按班级、再按班次排序。文件可以直接用同一页面的导入功能再读回来，方便备份、核对或在 Excel / WPS 中继续处理；需要完整还原点名与设置时仍请使用“导出完整备份”。

## 学生备注

学生详情页底部的“备注”链接会弹出编辑窗口：文本框可记录文字，下方可添加多张图片（图片只按缩略图罗列在文本框下方，不参与文字排版，可逐张删除，单击缩略图可放大预览，再点空白处或按 Esc 关闭预览）。文字输入后自动保存，关闭窗口即写回本地；添加的图片会先压缩到最长边 1280px，避免手机照片把本地数据和备份文件撑大。备注随“导出完整备份”一起保存和恢复。
